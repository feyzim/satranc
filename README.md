# satranc
Chess (Turkish name satranç)  that written on python by me a computer engineering student for learning python.


I'm a computer engineering student in Ankara University. 

In our first term we started to learn python.

So I started this chess project for learning basics of the python and object oriented programming.

I used mainly lists, dictionaries, funcitons and classes for this project.

For learning object oriented programming I used classes naturally and I made every piece and object.

I gave them color (black or white), location and the have been taken parameters.

For visualising the board I used matrices (lists that in a list) and ANSI format for creating black and white squares.

I also used list for storing location data and passing it to the other functions.
